手机备份助手 v1.0
========================================

【这是什么】
把手机（或任意一块硬盘上的文件夹）里的新增照片 / 视频 / 文档，
先对比出"哪些是新的"，你勾选之后再一次性备份到硬盘，需要的话再传 123 云盘。

特点：
- 浏览器界面，不用敲命令
- 来源和目标都能选（手机 → 硬盘、旧硬盘 → 新硬盘都行）
- 先对比后动手：没点"开始执行"之前，目标盘上不会写任何东西
- 同名文件自动跳过，不会重复导
- 可以只导照片 / 只导视频 / 只导文档，也能多选


【怎么用（3 步）】

1) 装 Node.js
   打开 https://nodejs.org  → 下载 LTS 版本 → 一路"下一步"装完
   （已经装过就跳过）

2) 建桌面图标
   双击本文件夹里的  创建桌面快捷方式.cmd
   → 桌面上会出现「手机备份助手」图标

3) 双击桌面图标开始用
   → 后台静默启动，浏览器自动打开界面
   → 按界面上的 1→6 步走：选来源 → 选目标 → 扫描文件夹 → 分栏对应 → 对比勾选 → 执行
   → 用完点网页右上角「退出」


【手机怎么连电脑】
手机：设置 → 关于手机 → 连续点"版本号"7 次（开启开发者选项）
手机：设置 → 系统和更新 → 开发者选项 → 打开"USB 调试"
数据线连电脑，手机弹窗点"允许"


【注意】
- 本压缩包里没有任何个人数据（不含照片、不含别人的路径、不含同步记录）
- 第一次用请自己选目标文件夹，程序不会乱写
- 如果 Windows 提示"此文件来自其他计算机，可能被阻止"：
  右键 zip 文件 → 属性 → 勾选"解除锁定" → 确定，然后再解压
